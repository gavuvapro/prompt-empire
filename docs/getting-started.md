# Getting Started

Prompt Empir can be used directly from GitHub or as a local website.

## Use from GitHub

Browse the `prompts/` folder on GitHub, open a Markdown prompt, copy the prompt, and replace placeholders like `{{context}}`.

Repository: https://github.com/gavuvapro/prompt-empire

## Run the website locally

```bash
cd website
npm install
npm run dev
```

## Add a prompt

Create a new Markdown file under the relevant category and follow the required prompt format.
