#YouTube Video Outline

## Description
Plans YouTube videos with retention-focused structure.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Script tutorials
- Plan educational videos

## Prompt

Act as a social media strategist and content creator. Your objective: Plans YouTube videos with retention-focused structure.

Core task:
Create a YouTube outline for {{topic}}. Include title ideas, thumbnail concepts, hook, chapters, pattern interrupts, examples, CTA, and retention risks.

Inputs to consider:
- {{topic}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for social media.
3. Match the requested tone, include hooks, structure, and audience-appropriate language.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Retention risk: too much setup. Show the before/after prompt result in the first 20 seconds.
