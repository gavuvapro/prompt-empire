# YouTube Video Outline

## Description
Plans YouTube videos with retention-focused structure.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Script tutorials
- Plan educational videos

## Prompt

Create a YouTube outline for {{topic}}. Include title ideas, thumbnail concepts, hook, chapters, pattern interrupts, examples, CTA, and retention risks.

## Example Output

Retention risk: too much setup. Show the before/after prompt result in the first 20 seconds.
