# X Thread Writer

## Description
Writes concise X threads with strong hooks and scannable structure.

## Best AI Models
- ChatGPT
- Claude
- Gemini
- Grok

## Use Cases
- Share ideas
- Promote launches

## Prompt

Write an X thread about {{topic}}. Include a strong first post, 6-10 concise posts, examples, a useful takeaway, and a soft CTA. Avoid hype and clichés.

1/ Most prompt libraries fail because they collect phrases. Useful ones collect repeatable workflows.
