# Shopify Store Audit

## Description
Audits Shopify stores for conversion, trust, UX, and SEO.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Improve conversion
- Prepare launches

## Prompt

Act as a Shopify conversion expert. Audit this store or page. Review above-the-fold clarity, product pages, trust signals, checkout friction, mobile UX, SEO, speed, and analytics.

Store/page details: {{details}}

## Example Output

Add a benefit-led headline above the product grid and move shipping/returns reassurance near the add-to-cart button.
