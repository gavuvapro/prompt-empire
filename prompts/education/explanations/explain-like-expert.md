# Explain Like an Expert Teacher

## Description
Explains complex ideas with intuition, analogies, examples, and checks for understanding.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Learn hard concepts
- Teach others

## Prompt

Explain {{concept}} to a motivated learner. Start with intuition, then formal definition, analogy, worked example, common mistakes, and five quiz questions. Adjust to level: {{level}}.

## Example Output

Intuition: A database index is like a book index — it speeds up lookup but costs space and maintenance.
