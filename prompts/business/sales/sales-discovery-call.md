#Sales Discovery Call Planner

## Description
Builds consultative sales discovery questions and qualification criteria.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Prepare calls
- Improve B2B sales

## Prompt

Act as a senior business strategist. Your objective: Builds consultative sales discovery questions and qualification criteria.

Core task:
Create a discovery call plan for selling {{product}} to {{buyer}}. Include call objective, agenda, qualification questions, pain probes, objection handling, next steps, and CRM notes template.

Inputs to consider:
- {{product}}
- {{buyer}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for business.
3. Include assumptions, success metrics, risks, and tradeoffs.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Pain probe: What happens if your team keeps solving this with the current workflow for another six months?
