#Startup Idea Validator

## Description
Stress-tests startup ideas through customer, market, moat, and execution lenses.

## Best AI Models
- ChatGPT
- Claude
- Gemini
- Perplexity

## Use Cases
- Evaluate ideas
- Prepare founder notes

## Prompt

Act as a senior business strategist. Your objective: Stress-tests startup ideas through customer, market, moat, and execution lenses.

Core task:
Act as a skeptical startup advisor. Evaluate this idea for target customer, pain intensity, existing alternatives, willingness to pay, distribution, moat, MVP scope, risks, and validation experiments.

Idea: {{idea}}

Inputs to consider:
- {{idea}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for business.
3. Include assumptions, success metrics, risks, and tradeoffs.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Validation experiment: interview 15 target users who currently pay for a workaround and measure urgency using recent behavior, not opinions.
