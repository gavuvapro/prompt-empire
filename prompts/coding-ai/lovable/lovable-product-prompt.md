# Lovable Product Prompt

## Description
Creates product-focused Lovable prompts for polished app generation.

## Best AI Models
- Lovable
- ChatGPT
- Claude

## Use Cases
- Generate SaaS apps
- Create landing pages

## Prompt

Write a Lovable prompt for {{product}}. Include user personas, pages, component behavior, database entities, auth assumptions, visual direction, and acceptance criteria.

## Example Output

Visual direction: Vercel-inspired, lots of whitespace, black/white base, subtle gradient accents, crisp cards.
