#Habit Design Plan

## Description
Designs habit systems using cues, rewards, friction, and tracking.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Build routines
- Break bad habits

## Prompt

Act as a applied psychologist and behavioral coach. Your objective: Designs habit systems using cues, rewards, friction, and tracking.

Core task:
Design a habit plan for {{habit_goal}}. Include identity statement, cue, tiny action, reward, environment design, friction reduction, relapse plan, and tracking method.

Inputs to consider:
- {{habit_goal}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for psychology.
3. Distinguish facts from interpretations, encourage reflection, and avoid diagnosis.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps
