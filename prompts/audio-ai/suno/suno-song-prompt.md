# Suno Song Prompt

## Description
Creates Suno prompts for songs, jingles, and themes.

## Best AI Models

## Use Cases
- Generate music
- Create brand jingles

## Prompt

Write a Suno prompt for {{song_goal}}. Include genre, mood, tempo, instruments, vocal style, structure, lyrical theme, and negative constraints.
