# Flux Photorealistic Scene

## Description
Generates detailed Flux prompts for photorealistic scenes.

## Best AI Models
- Flux

## Use Cases
- Create ads
- Generate realistic concepts

## Prompt

Create a Flux prompt for a photorealistic scene: {{scene}}. Include subject details, environment, lighting, camera, texture, mood, and negative prompt.

## Example Output

Photorealistic founder working late in a minimal studio, laptop glow, rain on window, 35mm lens, natural skin texture, no logos.
