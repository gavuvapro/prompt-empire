# DALL-E Product Mockup

## Description
Creates clear DALL-E prompts for product and interface mockups.

## Best AI Models
- DALL-E

## Use Cases
- Generate mockups
- Explore concepts

## Prompt

Write a DALL-E prompt for a clean product mockup of {{product}}. Specify object, environment, materials, lighting, camera angle, background, and what text to avoid.

## Example Output

A minimalist laptop mockup displaying an abstract prompt library dashboard, studio lighting, soft gray background, no readable text.
