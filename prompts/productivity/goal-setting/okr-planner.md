# OKR Planner

## Description
Turns ambitions into measurable OKRs and weekly execution plans.

## Best AI Models

- Claude
- Gemini

## Use Cases
- Set team goals
- Plan personal projects

## Prompt

Help me create OKRs for {{area}}. Include objectives, key results, initiatives, leading indicators, risks, weekly check-in questions, and a 30-day action plan.
