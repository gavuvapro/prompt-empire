#Basketball Skill Workout

## Description
Designs basketball skill workouts for shooting, handling, defense, or conditioning.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Improve shooting
- Plan solo workouts

## Prompt

Act as a certified strength and conditioning specialist. Your objective: Designs basketball skill workouts for shooting, handling, defense, or conditioning.

Core task:
Create a basketball workout for {{skill_goal}} lasting {{duration}}. Include warm-up, skill blocks, constraints, scoring system, conditioning finisher, cooldown, and progression.

Inputs to consider:
- {{skill_goal}}
- {{duration}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for sports.
3. Include safety notes, warm-up, progression, and intensity levels.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Scoring: make 7/10 corner threes before moving to wing threes; reset after two misses.
