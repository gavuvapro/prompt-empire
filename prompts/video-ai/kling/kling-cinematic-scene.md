# Kling Cinematic Scene Prompt

## Description
Creates cinematic Kling prompts with motion and atmosphere details.

## Best AI Models
- Kling

## Use Cases
- Generate cinematic clips
- Prototype scenes

## Prompt

Create a Kling prompt for {{scene}}. Include subject, movement, environment, camera path, lighting, physics details, mood, duration, and negative prompt.

## Example Output

Camera glides through a futuristic archive as prompt cards float into constellations, realistic motion, soft particles, 8 seconds.
