# Veo Product Demo Prompt

## Description
Creates video generation prompts for product demo sequences.

## Best AI Models
- Veo

## Use Cases
- Generate promos
- Visualize product launches

## Prompt

Create a Veo prompt for a {{duration}} product demo video. Include scene sequence, camera movement, transitions, lighting, mood, UI depiction, and audio direction if supported.

## Example Output

A 20-second cinematic product demo: close-up of creator searching prompts, smooth push-in, quick cuts to categories, clean studio lighting.
