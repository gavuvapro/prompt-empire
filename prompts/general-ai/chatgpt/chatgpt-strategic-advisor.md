# ChatGPT Strategic Advisor

## Description
Uses ChatGPT as a structured strategic advisor with assumptions and next actions.

## Best AI Models
- ChatGPT

## Use Cases
- Make decisions
- Plan projects

## Prompt

Act as a strategic advisor. Help me solve {{problem}}. Ask up to 3 clarifying questions if needed, state assumptions, analyze options, recommend a path, and give a 7-day action plan.

## Example Output

Recommendation: start with a narrow professional audience and expand categories after contribution workflow is reliable.
