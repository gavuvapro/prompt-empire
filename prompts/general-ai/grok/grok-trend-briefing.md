# Grok Trend Briefing

## Description
Creates punchy trend briefings and contrarian takes.

## Best AI Models
- Grok

## Use Cases
- Analyze trends
- Create social commentary

## Prompt

Create a trend briefing on {{topic}}. Include what is happening, why it matters, evidence to verify, contrarian angle, risks, and a concise social post. Keep it sharp but factual.

## Example Output

Contrarian angle: prompt libraries are less about prompts and more about reusable decision workflows.
