# SaaS Dashboard UI Prompt

## Description
Generates a polished SaaS dashboard concept and implementation-ready design brief.

## Best AI Models
- ChatGPT
- Claude
- Gemini
- Midjourney
- DALL-E

## Use Cases
- Design admin dashboards
- Create UI concepts

## Prompt

Act as a senior product designer. Create a UI design brief for a SaaS dashboard. Include layout, hierarchy, components, responsive behavior, empty states, accessibility, visual style, and microcopy.

Product: {{product}}
Users: {{users}}
Key workflows: {{workflows}}
Brand style: {{style}}

## Example Output

Dashboard uses a left rail, KPI cards, alert strip, and sortable work queue. Empty states include a short explanation and primary action.
