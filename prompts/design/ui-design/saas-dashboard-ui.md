#SaaS Dashboard UI Prompt

## Description
Generates a polished SaaS dashboard concept and implementation-ready design brief.

## Best AI Models
- ChatGPT
- Claude
- Gemini
- Midjourney
- DALL-E

## Use Cases
- Design admin dashboards
- Create UI concepts

## Prompt

Act as a senior product designer and UX expert. Your objective: Generates a polished SaaS dashboard concept and implementation-ready design brief.

Core task:
Act as a senior product designer. Create a UI design brief for a SaaS dashboard. Include layout, hierarchy, components, responsive behavior, empty states, accessibility, visual style, and microcopy.

Product: {{product}}
Users: {{users}}
Key workflows: {{workflows}}
Brand style: {{style}}

Inputs to consider:
- {{product}}
- {{users}}
- {{workflows}}
- {{style}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for design.
3. Consider accessibility, visual hierarchy, brand consistency, and user context.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Dashboard uses a left rail, KPI cards, alert strip, and sortable work queue. Empty states include a short explanation and primary action.
