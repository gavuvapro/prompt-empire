# Flyer Copy and Layout

## Description
Creates flyer messaging and layout guidance.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Promote events
- Create local campaigns

## Prompt

Create a one-page flyer for {{offer_or_event}}. Include headline, subheadline, benefits, agenda or offer details, CTA, trust signals, layout structure, and print-friendly notes. Audience: {{audience}}.

## Example Output

Headline: Build Better Prompts in One Afternoon. CTA: Reserve your seat today.
