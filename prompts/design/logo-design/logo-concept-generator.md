#Logo Concept Generator

## Description
Generates image-model-ready prompts for logo concepts.

## Best AI Models
- Midjourney
- DALL-E
- Flux
- Stable Diffusion
- Leonardo AI

## Use Cases
- Explore visual identities
- Create brand marks

## Prompt

Act as a senior product designer and UX expert. Your objective: Generates image-model-ready prompts for logo concepts.

Core task:
Create 5 distinct logo prompts for {{brand}}. Each prompt must include concept, symbolism, style, typography direction, color palette, constraints, and negative prompt. Optimize for {{image_model}}.

Brand description: {{description}}

Inputs to consider:
- {{brand}}
- {{image_model}}
- {{description}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for design.
3. Consider accessibility, visual hierarchy, brand consistency, and user context.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps
