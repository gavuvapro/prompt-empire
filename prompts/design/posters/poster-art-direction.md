# Poster Art Direction Prompt

## Description
Creates high-quality poster prompts for campaigns or events.

## Best AI Models
- Midjourney
- DALL-E
- Flux
- Stable Diffusion

## Use Cases
- Generate campaign posters
- Explore visual styles

## Prompt

Write a poster generation prompt for {{event_or_campaign}}. Include subject, composition, typography space, color palette, lighting, mood, medium, aspect ratio, and negative prompt. Make it suitable for {{image_model}}.

## Example Output

A bold editorial poster for an AI conference, luminous grid horizon, centered abstract neural monolith, ample top typography space, deep navy and silver.
