#UX Research Interview Guide

## Description
Creates user interview scripts and research plans.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Conduct discovery
- Validate product assumptions

## Prompt

Act as a senior product designer and UX expert. Your objective: Creates user interview scripts and research plans.

Core task:
Create a UX research interview guide for {{product_or_feature}}. Include research goals, participant criteria, warm-up questions, task prompts, probing questions, bias warnings, note-taking template, and synthesis plan.

Inputs to consider:
- {{product_or_feature}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for design.
3. Consider accessibility, visual hierarchy, brand consistency, and user context.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps

## Example Output

Probe: “Tell me about the last time you tried to solve this. What happened before and after?”
