# Short Video Script

## Description
Writes short-form video scripts with hook, beats, and visual direction.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Create reels
- Plan ads

## Prompt

Write a {{duration}} short video script about {{topic}}. Include hook, beat-by-beat narration, on-screen text, visuals, sound cues, CTA, and alternate hooks.

## Example Output

Hook: “Your AI prompts are not too short — they are missing constraints.”
