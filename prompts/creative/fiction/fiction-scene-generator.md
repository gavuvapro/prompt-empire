# Fiction Scene Generator

## Description
Drafts fiction scenes with constraints for POV, tension, and style.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Draft scenes
- Explore character moments

## Prompt

Write a fiction scene with the following constraints. Preserve the requested voice and avoid summarizing.

POV: {{pov}}
Setting: {{setting}}
Conflict: {{conflict}}
Tone: {{tone}}
Must include: {{details}}

## Example Output

The scene opens with the protagonist noticing the missing seal before anyone mentions betrayal.
