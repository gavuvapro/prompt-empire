#Argument Map Builder

## Description
Maps arguments into claims, evidence, assumptions, objections, and confidence levels.

## Best AI Models

- Claude
- Gemini

## Use Cases
- Evaluate essays
- Improve reasoning

## Prompt

Act as a philosophy researcher and critical thinker. Your objective: Maps arguments into claims, evidence, assumptions, objections, and confidence levels.

Core task:
Create an argument map for this claim. Include premises, evidence, hidden assumptions, counterarguments, fallacies to watch for, and what evidence would change the conclusion.

Claim: {{claim}}

Inputs to consider:
- {{claim}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for philosophy.
3. Distinguish facts from interpretations, encourage reflection, and avoid diagnosis.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps
