# Ethical Decision Matrix

## Description
Evaluates decisions through multiple ethical frameworks.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Assess product choices
- Prepare policy decisions

## Prompt

Analyze this decision using utilitarian, rights-based, justice, virtue, and care ethics perspectives. Include stakeholders, harms, benefits, trade-offs, safeguards, and recommendation.

Decision: {{decision}}

## Example Output

Safeguard: make donation links transparent and ensure free access is not degraded for non-donors.
