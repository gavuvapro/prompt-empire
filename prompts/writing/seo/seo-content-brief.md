# SEO Content Brief

## Description
Produces SEO briefs with intent, SERP angle, keywords, structure, and quality signals.

## Best AI Models
- ChatGPT
- Claude
- Gemini
- Perplexity

## Use Cases
- Brief writers
- Improve rankings

## Prompt

Create an SEO content brief for the keyword {{keyword}}. Include intent, audience, title options, meta description, outline, related keywords, FAQs, E-E-A-T signals, and differentiation angle.

## Example Output

Differentiation angle: include prompt evaluation criteria and downloadable examples instead of generic prompt lists.
