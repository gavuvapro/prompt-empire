# Expert Blog Outline

## Description
Creates authoritative blog outlines with search intent and original angles.

## Best AI Models

- Claude
- Gemini

## Use Cases
- Plan articles
- Create thought leadership

## Prompt

Create an expert blog outline for {{topic}}. Include search intent, thesis, audience, H2/H3 structure, unique examples, data needs, internal links, and expert quote opportunities.
