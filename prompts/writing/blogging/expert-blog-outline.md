#Expert Blog Outline

## Description
Creates authoritative blog outlines with search intent and original angles.

## Best AI Models
- ChatGPT
- Claude
- Gemini

## Use Cases
- Plan articles
- Create thought leadership

## Prompt

Act as a professional copywriter and content strategist. Your objective: Creates authoritative blog outlines with search intent and original angles.

Core task:
Create an expert blog outline for {{topic}}. Include search intent, thesis, audience, H2/H3 structure, unique examples, data needs, internal links, and expert quote opportunities.

Inputs to consider:
- {{topic}}
- {{audience}}
- {{goal}}
- {{context}}
- {{constraints}}

Workflow:
1. Review the inputs above. If required context is missing and prevents useful output, ask up to 3 targeted clarifying questions; otherwise, state explicit assumptions.
2. Apply the core task using best practices for writing.
3. Match the requested tone, include hooks, structure, and audience-appropriate language.
4. Deliver a structured response.

Output format:
- Brief objective
- Assumptions (if any)
- Deliverable with concrete, actionable details
- Risks or tradeoffs
- Next steps
